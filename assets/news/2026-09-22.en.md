Just today, we decided to move on to the development of Teeworlds Archive 0.8. The September 14 test version has been set as the default Steam version.

Changes:
- **Steam support**
- Better input method support
- zstd network compression introduced for 0.8; this will automatically be used on servers that support it
- The server list can now be preferentially sorted by both ping and player count at the same time.
- Improved parts of the UI
- Use Steam Linux Runtime 4.0 on Linux

If you need to use the **fcitx5** input method under **Wayland**, please use `SDL_VIDEO_DRIVER=wayland %command%` as a launch option.
This is a known issue with the new Steam Linux Runtime under Wayland.
